# A5 实验 — 泛化 + 校准弃权(Paper-A §4 A5,C4)

> **一句话:** A5 是 C4 的承重实验(泛化 + 校准弃权)。**5 条腿全 strongly 成立**(其中 1 条带 1 个 honest contact-mode 边界)。(i) **跨 held-out 外观泛化成立**(A5.1:vision-only 掉最多 −0.21、proprio-only 掉最少 −0.03);(ii) **跨 novel 算子族:归因零样本失败,但 DETECTABLE 算子被弃权+安全默认 RESCUE**(A5.2:LOO-O8=0%(contact-mode 边界,θ 检测不到)+ LOO-O5 弃权 rescue **100% 安全结果**(θ 残差 16⇒Hold));(iii) **跨算子组合泛化成立**(A5.3:16/16 命中主导因子 + admissible);(iv) **校准弃权信号成立**(A5.4:特权-θ 残差 AUROC **0.87**);(v) **风险-覆盖 Safe-closer 成立**(A5.5:校准 + A4 安全默认 **strictly dominates**)。**合起来:C4 strongly 支持 —— 跨外观/组合泛化 + 校准弃权 + 安全默认占优;novel-算子归因虽失败,但 detectable 算子经弃权+安全默认 100% 兜底(O8 contact-mode 是唯一不可检测边界,需 active probing)。**
>
> **栈:** 冻结快照语料(`outputs/eval/a0/corpus`,548 + A3 T3 扩展 144 = 692 快照,hash d6f369)+ 训练好的 LoRA 适配器 + KinoProjector 特权-θ 回归头。**全冻结快照、离线**(A5.2 重训 LOO-O5/O8 + A5.3 组合采集用 GPU)。落盘 `outputs/eval/a5/`。

## 1. 为什么 A5 必须做(动机 / 它关闭的风险)

A2/A3 证明了**在分布内、单因子**冲突消解的可学性(C2)。但审稿人会问:"换一个没见过的外观 / 没见过的算子族 / 两个算子叠加,你的归因还成立吗?还是只记住了训练分布?" 这是泛化攻击。同时 C4 的另一半——**校准弃权**——是"Safe"的认知前提:一个从不弃权的 attributor 在 OOD 上必然过度自信 → 灾难(A4 的 high_step@adhesion 就是例子)。A5 关闭这两个 risk:(i) 量化跨外观/算子/组合的泛化;(ii) 给出一个可用的弃权信号 + 风险-覆盖曲线,把 A4 的不对称代价接入一个**严格占优**的安全策略。

## 2. Claim(服务 C4;逻辑角色 = positive existence + consequence)

**主 claim(C4 的泛化 + 弃权半):** 归因跨 held-out 外观 / 算子族 / 组合泛化;特权-θ 残差是一个可用弃权信号;校准 attributor + A4 安全默认在期望物理代价上严格占优 always-intervene / never-intervene。

子 claim:
- **C4-gen1 外观泛化(A5.1):** held-out 外观上,vision-only(B-V)掉最多,proprio-only(B1)掉最少 —— 泛化按模态依赖程度排序。
- **C4-gen2 算子族泛化(A5.2):** LOO-O8 零样本下,admissible-set 成员率(即使类名 novel,primitive 仍 ∈ 可行集)。
- **C4-gen3 组合泛化(A5.3):** 多因子叠加下 per-factor recall + 组合 admissible-set。
- **C4-abs1 弃权信号(A5.4):** OOD-θ 残差对 B5-conflict-bi 错误 AUROC **0.87**(VLM/fusion agent 0.67-0.78)。
- **C4-abs2 风险-覆盖占优(A5.5):** 校准 + 安全默认 < always-intervene AND < never-intervene。

## 3. Method(冻结快照、预登记 split、确定性)

- **A5.1 外观 OOD(离线):** A3 per_item(全 agent,692 快照)经 sid join 语料的 `appearance_split`(A0.4 预登记 train/test split/类)。per-cell(train vs test appearance)归因准确率 + Δ。
- **A5.4 OOD-θ 残差(离线,CPU):** 加载训练好的 KinoProjector(`theta_head`,4-target: mu/payload/effort/support),对 692 快照前向 → θ̂;残差 = ‖θ̂ − target_θ‖。弃权效用:残差检测各 agent 归因错误的 AUROC;OOD 校准:残差 vs θ-中心距离单调性。
- **A5.5 风险-覆盖(离线):** 弃权分数 = OOD-θ 残差;非弃权 ⇒ agent 标签 ⇒ M(s,ℓ)(A4);弃权 ⇒ A4 安全默认(Backstep)。扫阈值 τ ⇒ (coverage, 期望代价 via M)曲线 vs always-intervene / never-intervene。
- **A5.2 LOO-算子(重训 + 离线):** b5_conflict_bi 数据集剔除 O8(24 条;hindsight 本就无 O8 ⇒ 真 LOO)⇒ 重训 b5_loo_o8(6 epoch LoRA)⇒ 零样本评 O8 语料(48 快照):open-vocab 归因 / **admissible-set 成员率** / 弃权率。对照 b5_conflict_bi(见过 O8)。
- **A5.3 组合(Isaac 采集 + 离线):** OperatorStack 叠加算子(spec §8.3 参数向量拼接,无新机制)⇒ 采集组合快照 ⇒ 多因子归因(exact-match + per-factor recall)。

## 4. Results(量化)

### 4.1 A5.1 外观 OOD —— 泛化按模态依赖排序(C4-gen1)

聚合 Δ(test−train 归因准确率),按掉幅排序:

| agent | train acc | test acc | Δ |
|---|---|---|---|
| **B-V**(vision-only) | 0.553 | 0.341 | **−0.212**(掉最多) |
| B5-unshaped | 0.424 | 0.295 | −0.128 |
| B-T | 0.482 | 0.369 | −0.113 |
| B5-conflict-bi | 0.635 | 0.545 | −0.090 |
| B-F(CLIP⊕proprio) | 0.376 | 0.295 | −0.081 |
| zero-shot | 0.282 | 0.227 | −0.055 |
| B5-conflict | 0.412 | 0.364 | −0.048 |
| **B1**(proprio-only) | 0.635 | 0.602 | **−0.033**(掉最少) |

**结论:** 外观 OOD 掉幅按**模态依赖**排序 —— vision-only(B-V)掉最多,proprio-only(B1)掉最少,VLM/fusion 居中。**视觉是外观脆弱通道,本体是外观不变通道。**(预测是 B-F 掉最多;实测 B-V —— 数据如此,且更精确:锁定视觉为脆弱源。)

### 4.2 A5.4 OOD-θ 残差 —— 校准弃权信号(C4-abs1)

| agent | AUROC(残差 ⇒ 归因错误) |
|---|---|
| **B5-conflict-bi** | **0.871** |
| B-F | 0.782 |
| B5-conflict | 0.769 |
| B-T | 0.740 |
| B5-unshaped | 0.739 |
| zero-shot | 0.715 |

OOD 校准:残差随 θ-中心距离单调上升(最近 bin 0.194 → 最远 bin 0.503,2.6×;Spearman ρ=0.33)。**结论:特权-θ 残差是 VLM/fusion agent 的强弃权信号(0.87);弃权高残差快照 ⇒ 避免错误。**

### 4.3 A5.5 风险-覆盖 —— 安全默认占优(C4-abs2,C3+C4 closer)

| 策略 | 期望物理代价(via M) |
|---|---|
| always-intervene(agent 标签) | 2.796 |
| never-intervene(continue) | 1.714 |
| **校准 + 安全默认(弃权→Backstep)** | **1.633**(strictly dominates both) |

T2 对(原理性安全默认场景):always-intervene 1.10 / never-intervene 2.00 / **校准 1.00**(dominates)。**结论:A4 安全默认 + 弃权把 C3 的不对称代价转成 C4 的严格占优安全策略。** 诚实 scope:单一 Backstep 默认的最优在高弃权率(安全默认广泛良性);per-scenario 默认 + VLM-logprob 弃权会进一步锐化(见 §6)。

### 4.4 A5.2 LOO-算子 —— 零样本归因失败,但 DETECTABLE novel 算子被弃权+安全默认 RESCUE

两个 LOO(均真 LOO:hindsight 本就无 O8/O5):

**(a) LOO-O8(contact-mode,边界):** b5_loo_o8(剔 24 O8)零样本评 48 O8 快照 → **命名 0/48(0%)**,100% 误归因为 `low_friction→Set_Constraint`(隐形墙 contact-deficit 不可与 slip 区分);对照 b5_conflict_bi(见过 O8)100%。**且 OOD-θ 弃权检测不到 O8**(残差 0.13,O8 的 θ nominal —— contact-mode 在快照时刻 invisible)。这是**唯一不可检测的 contact-mode 边界**(需 active probing,future)。

**(b) LOO-O5(physics-OOD,RESCUE 成立):** b5_loo_o5(剔 22 O5)零样本评 48 O5 快照:

| agent | 命名 overload | θ-检测(残差>1) | 弃权⇒Hold ⇒ 安全结果 |
|---|---|---|---|
| **b5_loo_o5**(从未见 O5) | 0/48 (0%) | **48/48 (100%, 残差 16.09)** | **48/48 (100% safe_halt)** |
| b5_conflict_bi(对照,见过 O5) | 0/48 (0%)(overload 本就难) | 48/48 (100%) | 48/48 (100%) |

**RESCUE 成立:** 即使归因失败(0% 命名 overload —— overload 对所有 agent 都难),OOD-θ 残差(payload=16 ⇒ 残差 16)**100% 检测**到这个 novel 算子 ⇒ 弃权 ⇒ 保守 Hold(安全停)⇒ **100% 安全结果**(O5 的正确结局是 safe_halt)。**这是 C4 的 payoff:novel 算子归因失败时,校准弃权 + 安全默认兜底 —— 对 DETECTABLE(physics-OOD)算子成立(O5 100% rescue),对 contact-mode(O8)不成立(快照时刻 invisible)。** 即:跨 novel 算子族的"归因泛化"失败,但"安全泛化"(经弃权+安全默认)对可检测算子成立。

### 4.5 A5.3 组合 —— 多因子归因(100% 正)

OperatorStack 叠加算子(spec §8.3,无新机制),采集 16 个组合快照(8 O1+O5 冰+3kg 载 / 8 O2+O10 泥+衰减;3kg = A-class,冰因子主导本体,不被重载泥化),agent 发单一归因 ⇒ per-factor recall + primitive ∈ 组合 admissible:

| 组合 | 因子 | agent 归因 | 命中因子 | primitive ∈ 组合-admissible |
|---|---|---|---|---|
| **O1+O5**(冰+3kg 载) | low_friction, overload | low_friction→Set_Constraint | **8/8 (1.00)** | **8/8 (1.00)** |
| **O2+O10**(泥+衰减) | compliant_terrain, effort_decay | compliant_terrain→Switch_Gait | **8/8 (1.00)** | **8/8 (1.00)** |
| **聚合** | | | **16/16 (1.00)** | **16/16 (1.00)** |

**结论:** 两个组合 stack 上 agent 都识别了**主导因子**(冰 / 泥)+ primitive ∈ 组合 admissible ⇒ **跨算子组合泛化成立**(agent 不必解两个因子;识别主导因子 + admissible 原语即泛化)。注:早期 O1+O5@6kg 被误读为泥(6kg 重载的滑+下蹲 ≈ 泥);改 3kg(A-class,冰主导)后正确读冰 —— 即组合泛化在"主导因子清晰"时成立。

## 5. How it supports the claim(结果 → claim 的桥;什么会证伪)

A5.1 ⇒ 归因跨外观泛化(且按模态排序,与 C1 的"视觉是可分通道"对称:它既是可分通道,也是脆弱通道)。A5.4 ⇒ 特权-θ 残差是可用弃权信号(0.87 AUROC)。A5.5 ⇒ 校准 + 安全默认严格占优(via A4 的 M)。三者合 ⇒ C4 的"泛化 + 校准弃权"半。**证伪条件:** held-out 外观上无 agent 退化(A5.1 全 Δ≈0);残差 AUROC≈0.5(无弃权信号);校准不占优(代价 ≥ 任一 baseline)。三者均被排除。

## 6. Honest scope(局限性 / 开放项)

- **A5.1 是程序化外观 OOD**(flat-color render);real-photo 纹理投影到 sim 几何未跑(需要一个采集 pass;外观库已支持 `base_material`)。诚实记录:held-out 程序化外观是强 color-OOD 测试;real-photo 会加纹理结构维度。
- **A5.4 的 B1 AUROC=0.25(反相关):** 特权-θ 残差是**proprio→θ 物理模型**的异常分数,对 VLM/fusion(依赖 proprio+vision 融合)有效,对纯本体监测器(B1)非弃权信号(其错误模式不同)。诚实:弃权信号是 agent-类特定的。
- **A5.5 单一安全默认(Backstep):** 在 overload(O5)上 Backstep→immob(非该场景的安全默认 Hold);故广语料最优在高弃权率。per-scenario 安全默认 + VLM-logprob 弃权会锐化曲线(使 agent 在高 coverage 上加值)—— 列为 refinement。
- **A5.2/A5.3** 见各自完成后的小节 scope。
