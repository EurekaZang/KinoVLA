# A5 实验——外观泛化、未见算子、组合与选择性预测（Paper-A §4，C4）

> **结论先行。** A5.1–A5.5 的边界结论保持不变：原始不确定性分数不能严格击败 always-safe，未见算子命名和 θ-OOD 主张仍不成立。新增 A5.6 不改 VLA/Projector，而是在其后加入可审计的 See–Feel–Act 结构化门控；门控冻结后，在 288 个 final-v2 快照和 300 个六外观簇确认性复现快照上，分别把 A4 物理代价从 `1.75→1.5417` 和 `1.72→1.52`，相对 always-safe 的两阶段 95% CI 分别为 `[-0.2083,-0.2083]`、`[-0.20,-0.20]`。因此 C4 现在有一个严格限定但成立的正结论：**在校准材质支持域内，结构化选择性恢复严格优于 always-safe；这不等价于全面 OOD、未见算子或 learned θ-boundary 已解决。**

## 1. 论文问题与冻结协议

A5 回答四个互不替代的问题：

1. 同一物理原因换成留出外观后，归因是否保持？
2. 完全未见的算子族能否被零样本命名？
3. 两种原因同时出现时，模型能否至少选到一个主导原因和可接受动作？
4. 不确定性分数能否在未参与阈值选择的外观上降低 A4 物理代价？

所有主分析都使用 A3 的冻结 692 个快照和 A4 的实测 `M(s,a)`。A5.5 只用 `appearance_split=train` 选择阈值，再在 `appearance_split=test` 上报告一次结果；实际动作由 `primitive + primitive_params` 严格映射，不能把所有 `Switch_Gait` 都当作 `high_step`。置信区间使用 2,000 次两阶段 bootstrap：在每个场景内重采样外观簇，同时在每个 A4 `(scenario, action)` 单元内重采样物理 episode。

## 3. A5.1：冻结外观留出

每个 agent 都有 340 个 train-appearance 和 352 个 test-appearance 快照。表中是跨 T1–T5 的样本加权归因准确率；它用于描述外观敏感性，不等价于跨场景宏平均。

| agent | train | test | test − train |
|---|---:|---:|---:|
| B1 | 0.447 | 0.455 | **+0.007** |
| B5-conflict | 0.353 | 0.307 | −0.046 |
| B-T | 0.353 | 0.307 | −0.046 |
| B-F | 0.365 | 0.284 | −0.081 |
| B5-conflict-bi | **0.576** | **0.489** | −0.088 |
| B5-unshaped | 0.365 | 0.239 | −0.126 |
| zero-shot | 0.382 | 0.256 | −0.127 |
| B-V | 0.459 | 0.284 | **−0.175** |

主要现象不是一个单调的“模态越丰富越稳”排序：

- B-V 总体跌幅最大，说明视觉外观 shortcut 确实存在。
- B1 总体几乎不变，但其绝对能力并不高；“稳”不能解释为“更好”。
- B5-conflict-bi 的 test 准确率最高，但在 T2 上从 1.000 降至 0.333，在 T3 上从 1.000 降至 0.846。
- 所有训练 agent 的 T5 决策归因均为 0；只有 zero-shot 在 train/test 为 0.531/0.385。T5 的真值是 `nominal/continue`，旧版按底层物理类别计分的结果已作废。

因此 A5.1 支持“外观依赖是可测的且按方法/场景异质”，不支持“方法已经实现外观不变归因”。

## 4. A5.2：未见算子族

### 4.1 LOO-O8（contact-mode）

剔除 O8 训练样本后，在 48 个 O8 快照上：

- 正确命名 `invisible_obstacle`：0/48，Wilson 95% CI `[0, 0.074]`；
- admissible primitive：0/48；joint：0/48；
- 见过 O8 的对照模型为 48/48。

模型主要把不可见接触障碍解释为 `low_friction`。O8 的 θ 接近 nominal，残差不能可靠标出它；这表明被动单快照对 contact-mode 的可识别性有限，未来需要主动探测或时间展开证据。

### 4.2 LOO-O5（payload/physics）

LOO-O5 与“见过 O5”的对照模型都在 48 个 O5 快照上得到：

- 命名 `overload`：0/48；
- mean θ residual：16.087；
- 以 residual 阈值触发 Hold：48/48。

这证明极端 payload 是可被 θ 残差检测并安全停机的，但**不能归因于 LOO 泛化**：见过 O5 的模型同样没有命名成功。它是一个 detectable-physics safety fallback，而不是 novel-operator semantics 的正证据。

## 5. A5.3：预选组合

两个冻结组合各 8 个快照：`O1+O5` 与 `O2+O10`。B5-conflict-bi 在 16/16 中命中至少一个真实因子，且所发 primitive 均在组合 admissible set 内。

该结果只说明接口能处理两个预选组合。样本来自 2 个 stack、每个 8 个 seed，没有未见组合族、跨外观簇或物理后果验证，不能写成一般组合泛化。

## 6. A5.4：θ 残差是错误排序诊断，不是 θ-OOD 证明

在 692 个快照上，`‖θ̂−θ‖` 检测归因错误的 AUROC 为：

| agent | AUROC | n / errors |
|---|---:|---:|
| B-F | **0.897** | 692 / 468 |
| B5-conflict-bi | 0.869 | 692 / 324 |
| B-T | 0.833 | 692 / 464 |
| B5-conflict | 0.786 | 668 / 440 |
| B5-unshaped | 0.772 | 692 / 484 |
| B-V | 0.706 | 692 / 436 |
| zero-shot | 0.571 | 485 / 265 |
| B1 | 0.418 | 692 / 380 |

残差与 θ-centroid distance 的秩相关为 `ρ=0.332`，最远 bin 的 mean residual 为 5.0034。但 `n_outside_train_range=0/692`，所以 OOD AUROC 未定义。重复的分位点还导致若干 bin 边界相同。论文中必须称它为**in-range error-ranking diagnostic**，不能称为 held-out θ-OOD 校准。

## 7. A5.5：泄漏受控的风险—覆盖结果

### 7.1 broad-overlap（8 个 A3↔A4 重叠场景）

校准集 288、测试集 300；各有 16 个场景×外观簇。校准集选择的最低代价阈值是 coverage=0，在测试集退化为 always-safe：cost 1.520。

| 测试策略 | coverage | expected cost | 相对 always-safe |
|---|---:|---:|---:|
| always-safe Backstep | 0 | **1.520** | 0 |
| 最小非零覆盖阈值 | 0.0533 | 1.840 | +0.320 |
| 目标 25%（可达点） | 0.1067 | 2.160 | +0.640 |
| 目标 50% | 0.5467 | 2.440 | +0.920 |
| 目标 75% | 0.7733 | 2.440 | +0.920 |
| always-agent | 1 | 2.960 | +1.440 |
| always-continue | 0 | 1.840 | +0.320 |

两阶段 bootstrap 对最小非零点给出 `selective − safe = [0.320, 0.320]`，即显著更差；它只显著优于 always-agent。残差可排序错误并不自动产生有用的物理代价排序。

### 7.2 T2 adhesion/mud 专项

校准 108、测试 132。matched-O4 与 matched-O2 的 proprio window 按构造逐字节相同，所有残差都等于约 0.103700，只有 coverage 0/1 两个端点，`selective_identifiable=false`。校准选择 coverage=1 后，测试 cost 为 1.6364，而 always-safe 为 1.000；这里还出现明显 appearance shift。该协议直接证伪“θ 残差可以解决 T2 选择性决策”。

## 8. A5.6：冻结的 See–Feel–Act 结构化门控

### 8.1 为什么不是继续调 A5.5 阈值

A5.5 已经证明单一 residual/entropy/MSP 阈值不够。A5.6 保留该负结果，改为一个后置的、机制约束的 selective recovery：

1. **Act 一致性：** VLA 实际动作必须是 `Switch_Gait(mode=high_step)`；
2. **语义一致性：** VLA 显式归因必须是 `compliant_terrain`，且该动作与冻结 recovery registry 一致；
3. **See 支持域：** 当前 RGB 的 dominant-chromatic 特征到两个 train-mud 原型的最近 L2 距离不得超过 `0.13283753`；
4. **Feel 异常证据：** 500 ms 本体窗口的可观测 peak tracking error 不得低于 `0.15150436`；
5. 任一条件不满足就执行 A4 consequence matrix 推导的 `backstep_detour` safe fallback。

部署决策只读取 `agent_label / attribution / RGB / proprio`。`truth`、scenario、appearance ID、θ、split 和物理代价均列入 forbidden inputs。阈值使用原 train calibration 加已经检查过的 development 数据拟合；第一批极端颜色集只用于暴露 shortcut 和改进方法，状态明确标为 `method_development_not_headline`。

冻结配置为 `configs/eval/c4_structured_gate_v2.yaml`，SHA-256=`1d538a3119c96079d41a5abb1aff3068005794aefdb4b071f3ac4b6499287bbd`。两个确认性语料的 manifest 都记录并匹配该哈希。

### 8.2 独立 final-v2 与六外观簇复现

| 冻结评估 | 快照 | 放行外观簇 | coverage | ours cost | always-safe | paired Δ | 两阶段 95% CI | 放行归因精度 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| final-v2 | 288 | 2 | 0.2083 | **1.5417** | 1.7500 | **−0.2083** | `[−0.2083,−0.2083]` | 60/60 = 1.00 |
| confirmatory replication | 300 | **6** | 0.2000 | **1.5200** | 1.7200 | **−0.2000** | `[−0.20,−0.20]` | 60/60 = 1.00 |

复现集使用 24 个全新 appearance ID（每个语义族 6 个），67 个精确去重后的模型输入；六个被放行泥地外观簇均未参与训练、方法开发或 final-v2，且六簇均严格改善 `−1.0`。把外观簇作为 Bernoulli 单位的单侧 exact sign test 为 `p=0.015625`。两套评估的每个外观簇 `ours−safe≤0`，且 headline gate 同时要求 coverage≥0.10、paired CI 上界<0、放行归因精度=1、语料 gate hash 一致，最终全部通过。

区间退化为常数不是把快照当独立样本：bootstrap 先在每个 scenario 内重采样外观簇，再重采样 A4 `(scenario,label)` episode。这里六个独立泥地簇都作出相同的正确放行，A4 对应物理单元的 10 个 episode 代价也一致，因此每次 paired draw 相同。论文同时报告外观簇数，避免用 60 个快照伪装 60 个独立外观证据。

### 8.3 不干扰其他论断

- VLA、Projector、训练语料和 A1–A4 artifact 均未改动；A5.6 只是部署时后置门控。
- 冻结推理 checkpoint 为 `adapter_model.safetensors` SHA `b1b4c611…40bd66`、`kino_projector.pt` SHA `63236296…b8e4a`；两者 mtime 均为 2026-07-03，早于 2026-07-19 gate freeze 和 final collection。
- A5.1–A5.5、A6 和 A7 的负结果不被改写：LOO 命名、θ-OOD、单分数 abstention、learned boundary 仍不成立。
- C4 的正面范围仅是“**冻结支持域内的新外观 + consequence-aware selective recovery**”；支持域外一律回退，不能写成 open-world material recognition。

## 9. 对 C4 的可发表判决

| 子主张 | 判决 | 可写入论文的表述 |
|---|---|---|
| 外观泛化 | 部分支持 | 有冻结外观留出统计，但存在显著场景依赖和下降 |
| 未见算子命名 | 不支持 | O8/O5 都是 0%；O5 仅能被极端 θ 残差安全兜底 |
| 组合泛化 | 初步可行 | 两个预选 stack 上 16/16，不作一般化主张 |
| θ-OOD 校准 | 不支持 | 无训练范围外 θ；仅有 in-range 错误排序 AUROC |
| 单一 residual 阈值非零覆盖优于安全默认 | 不支持 | A5.5 broad 与 T2 都未超过 always-safe |
| 支持域约束的结构化 selective recovery | **支持** | 两个独立冻结语料均严格优于 always-safe；六新外观簇复现，放行精度 1.00 |

A5 的发表价值在于：它先用预登记 split、物理代价和双层不确定性证伪“高 AUROC 就等于安全选择”，再用不改基模型的结构化 See–Feel–Act 共识门控闭合 consequence-aware selective recovery。可发表的 C4 正结论来自 A5.6 的冻结独立验证；A5.1–A5.5 的失败边界仍作为 falsifier 和适用范围，不能被 A5.6 偷换成全面 OOD 主张。
