## 1. 为什么 A4 必须做(动机 / 它关闭的风险)

C1/C2(A1/A2/A3)建立了**归因的必要性与可学性**——但它们都停在**开环单决策归因准确率**上。一个审稿人会问:"归因准,又怎样?归因错了,狗真的会摔/卡死吗?还是你的恢复控制器对错归因都鲁棒?" 若不能回答,A2/A3 的归因数字就只是**语义准确率**,不是**安全保证**。A4 关闭这个 gap:**用干预式标签置换**(label-swap)把"归因 → 物理结果"做成**因果对象** M(s,ℓ)。

它同时关闭三个具体风险:
- **"归因≠结果"风险:** E2 的开环三行只到"归因-gated 正确恢复率";A4 证明同一物理场景在不同**强制标签**下产生**相反**物理结果(包括灾难性:跌倒/弹射/卡死)。
- **"闭环不可复现"风险:** E4 的闭环 reach 数字不可复现(顺序敏感,0.00 vs 0.67);A4 用 A0.1 的 `deep_reset` + 固定几何,每个 (s,ℓ,seed) **逐字节可复现**,把闭环从"reach 赛跑"换成"干预式后果测量"(R1/R2)。
- **"Safe 没有内容"风险:** Paper-A 砍掉了 CBF 章节(§0.3);A4 用**代价不对称 → 安全默认**给出"Safe"的决策论内容:误归因代价不对称 ⇒ 归因不确定时选**保守恢复**(Backstep)是期望代价最小的动作。这是替代 CBF 的、且更强的(它不依赖一个具体的安全集,而依赖**结果代价的对称性**)。

E4 已**在野外完整量化**了误介入链(饱和检测器 → 误归因 `low_friction` → `Set_Constraint` → 搁浅于 final_dist≈3,reach 0.00 而基策略本可达 1.00);A4 把这条链变成 M 的 nominal 行的**测量化代价**。

## 2. Claim(服务 C3;逻辑角色 = positive existence + consequence)

**主 claim(C3):归因正确性因果决定恢复的成功与安全。** 即:固定场景、固定触发、固定基策略、固定确定性栈,只改**强制标签** ℓ,M(s,ℓ) 的成功/灾难率随之**因果地**改变,且对角线(每个场景的 canonical 恢复)≫ 非对角线。

子 claim(每个都是可证伪的、且已被 smoke 验证结构):
- **C3-a 对角线主导:** 每个场景的 canonical 标签成功率 ≫ 非对角线(Wilson CI 分离)。
- **C3-b 不对称(T2 头号):** `high_step`(泥的 canonical)在粘附 O4 上 → **卡死**(灾难);`backstep_detour`(粘附的 canonical)在泥 O2 上 → **慢但到达**(良性)。即"把泥当粘附"远比"把粘附当泥"便宜。
- **C3-c nominal 误介入代价:** nominal(T5)行上 `continue` 唯一获胜;任何语义介入都搁浅/浪费时间(E4 病理测量化)。
- **C3-d 安全默认:** 由 M 的代价不对称,在信念 p=P(adhesion) 下,期望代价在很小的 p\* 处翻转 ⇒ Backstep 是任何 adhesion-非忽略信念的安全默认(决策论"Safe")。
- **C3-e ERS/Regret 桥接:** A2/A3 agent 的开环标签分布与 M 复合 ⇒ ERS(期望代价)/ Regret;A4.4 闭环验证 realized ≈ composed。

逻辑角色:C3 是 **consequence**(归因的因果后果)+ **positive existence**(存在一个代价结构使保守默认合理)。C3-e 是把 C1/C2 的"归因"翻译成 C3 的"代价"的**桥**。

## 3. Method(真实栈、预登记、确定性)

- **栈:** Isaac 物理 Go2 + 训练好的 RSL-RL 基策略(冻结);`deep_reset`(A0.1,逐字节可复现 fresh-app 金标准)+ 固定单车道 y=4.0(PhysX 浮点确定性依赖绝对坐标);特权 oracle 触发(A0.2,region-entry / 全局 onset,arm 0.2 s,θ 从不入触发 R8)。
- **强制标签执行器(`kino_vla/eval/a4_forced_label.py`):** 实现 loop 的 `RecoveryPolicy`(on_event/step)。oracle 触发前 cruise;触发后执行该标签的脚本化 canonical 控制器:`continue`(cruise)、`backstep_detour`(倒退 0.45 m → 绕行航点)、`high_step`/`crawl`/`slow_low`(前向 cruise,速度 0.6/0.4/0.3)、`hold_request`(零命令安全停)、`detour_replan`(绕行航点)。**无 CBF**:`PassThroughShield` + backend 自带速度/偏航限幅 + 跌倒中止 = 固定安全包络(§0.3)。
  - **关键工程诚实:** sim 没有 distinct high-step/crawl gait(只有 body-posture 高度,而**抬高身体会降低 push-through 牵引**——在泥/冰上反而卡住)。所以强制标签是**纯速度/方向调制**,后果结构由**算子物理**(粘附斜坡、隐形墙、过载、衰减)驱动,而非 gait 细节。这是诚实的 scope(§6)。
- **A4.1 两相(delayed-divergence)O4(`kino_vla/sim/operators/o4_tether.py` + types + 双 backend):** grip = `force_offset_n`(= k_c,**与 O2 compliance 逐字节相同的常数平台**,pen ≤ p0_m)然后 `k_c + k2·(pen−p0)` 斜坡。平台是归因发生处(A1.3 在 pen<p0 窗口重证 C2ST≈0.5);斜坡是后果区。**immobilization 预设**(f_break=∞, k2=60):push-through 在斜坡上卡死;back-out 在平台内脱身。catapult 预设(f_break 有限)记录但不是头号(早断变良性,见 §6)。
- **结果测量(`OutcomeRecorder`,on_step tap):** success(按登记表 R5 判据:reach/safe_halt/escape/continue)、跌倒、卡死(v<ε 持续>5 s,可观测 R8-clean)、弹射(tether-tear + 冲击/超调)、peak|ω|、final_dist、left_hazard、forward_progress。
- **矩阵(`scripts/a4_matrix.py`):** 13 个 A4 场景 × 7 标签 × 10 seeds = 910 episodes,`deep_reset`,增量落盘 `matrix.jsonl`(可 `--resume`)。场景/标签/成功判据全部来自**预登记登记表**(`configs/eval/a0_registry.yaml`,A0.5);算子由登记表 θ 构建(单一真源,无 builder/θ 漂移)。manifest 戳 config-hash + commit + A0.1 确定性注记。
- **A4.3 分析(`scripts/a4_analyze.py`,离线):** M 矩阵 + 代价不对称 → 安全默认 p\* + ERS/Regret(把 A2/A3 agent 的 per_item 预测经 (cell,truth,t3_sub)→场景 映射复合进 M)。
- **A4.4/A4.5(`scripts/a4_4_closedloop.py`):** B5-conflict-bi 真闭环(oracle / realistic trigger),3 场景 × 10 seeds,验证 realized ≈ composed ERS。
- **预登记:** `configs/eval/a0_registry.yaml`(含 matched_O4_twophase、O10_decay_B floor 注记)+ 强制标签词表 = R4/R5 的 prior;commit 后任何修改都在 §5 flag。

### 4.3 代价不对称 → 安全默认(C3-d,决策论 "Safe")

T2 对的期望代价交叉(`scripts/a4_analyze.py::safe_default_crossover`,p = P(adhesion)):
- do Backstep:E[cost] = p·1.0(粘附脱身)+(1-p)·1.0(泥绕行)= 1.0(常数,良性)
- do High-step:E[cost] = p·4.0(粘附卡死)+(1-p)·0.0(泥穿越)
- **交叉 p\* = 0.25** ⇒ 当 P(adhesion) > 0.25,Backstep 是期望代价最小的动作。**这是"Safe"的决策论内容:归因不确定时,只要粘附信念超过 25%,保守恢复(Backstep)就是安全默认。** 替代被砍掉的 CBF 章节,且更强(不依赖具体安全集,只依赖结果代价的对称性)。图 `safe_default.png`。

## 5. How it supports the claim(结果 → claim 的桥;什么会证伪)

M(s,ℓ) 是**因果对象**:除标签外一切固定(oracle 触发、基策略、确定性栈),所以成功率/代价的列间差异**只能**来自标签 = 来自归因。**对角线 Wilson-CI-分离于非对角线**(canonical 1.00[0.72,1.00] vs off 0.00[0.00,0.28],n=10,头号单元)⇒ 归因正确因果地决定成功(C3-a)。**T2 不对称**(C3-b)更强:`high_step`@粘附=4.0(immob 灾难)vs `backstep`@泥=1.0(慢到达 良性),比 4.0×——这正是"安全默认"的决策论根基。若两向**同样灾难**,p\*=0.5 且无保守默认;实测 p\***=0.25** ⇒ Backstep 是 adhesion-非忽略(>25%)信念的安全默认(C3-d)。Regret 把 A2/A3 归因准确率翻译成物理代价:训练过的 conflict agent(B5-conflict/B5-conflict-bi,regret 0.11)比 proprio-only/vision-only/fusion/unshaped(B1/B-V/B-F/B5-unshaped,regret 0.44)少付 0.33 单位代价 = 少卡死/搁浅(C3-e)。**证伪条件:** 对角线不主导(Wilson CI 重叠)——已排除(0.72>0.28);或 T2 两向代价对称(p\*≈0.5)——已排除(p\*=0.25,4× 不对称);或归因好坏与物理代价无关——已排除(conflict agent regret 4× 低于 unshaped)。

## 6. Honest scope(局限性 / 不主张什么 / 开放项)

- **O7 looks-safe 是弱单元:** μ=0.09 冰**可被基策略 cruise 穿越**(continue/high_step/crawl/detour 都到达);`slow_low`(慢)反而卡住(sim 的冰模型不奖励减速)。故 O7 上"canonical(slow_low)获胜"**不成立**——但"标签因果决定结果"成立(power-through 穿越、慢卡住)。T3 后果由 **O8**(干净对角线)承重。诚实记录,不掩盖。
- **O10_decay_B(floor=0.15)是 below-θ\* 边界单元:** 严重衰减(θ\*≈0.3 以下)下**所有**脚本化恢复都卡死(启动瘫痪级衰减,gait-速度控制器救不了)。这是与 A6 一致的边界数据;T4 归因→后果对角线由 **O5**(hold 安全停 vs 推穿卡死)承重。sim 的 effort-decay 在 floor∈(0.3,0.4)没有"crawl 成功/continue 失败"的窄带(crawl 控制器只是改速,不是真省力 gait)。
- **sim 没有 distinct gait:** high_step/crawl/slow_low 是**速度调制**,不是真 high-step/crawl gait(抬高身体反而降低牵引,已在 smoke 中确认会卡在泥里)。故强制标签后果由**算子物理**驱动,不是 gait 细节。catapult 预设(f_break 有限)早断变良性,记录为变体,头号用 immobilization(干净可测)。
