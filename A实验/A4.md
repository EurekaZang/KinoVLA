# A4 实验 — 干预式后果矩阵与动作组合审计

> A4 是 C3 的物理后果实验。它在 Isaac Go2 physics simulation 中固定场景、触发器、低层策略和随机种子,只强制恢复标签,得到 `M(s,ℓ)`。当前可稳健支持两点:(1)若干干净场景中恢复标签因果改变成功/失败;(2)T2 粘附/泥的错误代价不对称,推出 `p*=0.25` 的 Backstep 安全默认。2026-07-18 的新版分析同时区分“代理实际输出动作”和“归因所蕴含动作”,修复了旧版丢失 `Switch_Gait.mode`、缺失场景按0代价处理、ERS用分布而regret用argmax等问题。

## 1. 冻结产物与估计量

- 物理矩阵:`outputs/eval/a4/matrix.jsonl`,630条=9场景×7标签×10 seeds(700–709),SHA-256 `7211a437d5bc5e1e5e50a06bc2d43f16fdb2d1aba0475c8a0e81dd89eb6d5789`。
- 分析结果:`outputs/eval/a4/a4_results.json`,schema v2,SHA-256 `4ad759868a4f77a13829e8d396aa5e562e96264374145804249ae1c1e9d0c081`。
- A3 输入:每个代理692条同版本重评结果;完整保存 `primitive_params`;所有 `Switch_Gait` 都有观测到的 `high_step/crawl` mode。
- 物理代价:clean=0,slow/detour=1,stranded=3,immobilized=4,catapult=5,fall=6。
- `actual_action`:真实 `primitive+params` 映射到 M 的标签。
- `attribution_implied`:归因经冻结 taxonomy 映射到 canonical 动作,仅作机制诊断,不冒充实际执行动作。
- ERS:`E_s E_{ℓ~agent}[cost(s,ℓ)]`。
- regret:`E_s[ERS(s)-min_ℓ M_cost(s,ℓ)]`;使用完整经验分布,不再使用argmax。
- canonical gap:`ERS(s)-M_cost(s,canonical(s))`;允许为负,因为 O7/O10 弱单元中预登记 canonical 并非实测最优。
- 不确定性:2,000次配对两阶段 bootstrap;在每个场景内重采样 appearance cluster,同时在每个 `(s,ℓ)` 内重采样物理 episode。所有代理共享同一批重采样 sample id。

A3 与 A4 的可组合交集是8个场景。`O10_A_nominal` 在矩阵中存在,但 A3 冻结语料没有对应快照;旧版把它的缺失分布当成0代价,新版明确排除并记录 `matrix_scenarios_without_a3_rows=[O10_A_nominal]`。

## 3. T2 代价不对称与安全默认

| truth / action | Backstep | High-step |
|---|---:|---:|
| adhesion / matched-O4 | 1.0 | **4.0 immobilized** |
| mud / matched-O2 | 1.0 | **0.0 clean** |

令 `p=P(adhesion)`:

- `E[cost|Backstep]=p·1+(1-p)·1=1`;
- `E[cost|High-step]=p·4+(1-p)·0=4p`;
- 交点 `p*=0.25`。

因此当粘附后验超过25%时,Backstep 是这一个二元决策对中的期望代价最小默认。这个结论仅适用于 T2 adhesion/mud 对;不能把 Backstep 叫作全 taxonomy 的安全动作,例如它在 O1 nominal 上代价为6。

## 5. T2 与 nominal 分层暴露的机制边界

T2 两场景中:

| agent | ERS↓ | regret↓ | success↑ |
|---|---:|---:|---:|
| B5-unshaped | **0.50** | **0.00** | 1.00 |
| B5-conflict / B-T | 0.80 | 0.30 | 0.90 |
| B1 | 1.00 | 0.50 | 1.00 |
| B5-conflict-bi / B-F | 1.10 | 0.60 | 0.80 |

B5-unshaped 在 matched-O4 上有40%归因错误,但仍发出物理上可行的 Backstep;所以 attribution-gated A2 指标变差,而实际动作代价仍为最优。这证明“归因错误必然造成动作错误”并不成立,必须同时报告归因、动作及一致率。A4 的因果矩阵证明标签影响结果,但不能自动把 A2 的语义归因差异翻译成安全差异。

两个有 A3 快照的 nominal 场景(O1_A/O2_A)上,所有7个被组合代理的 composed success 都为0、ERS均为3。A3纠正后的 T5 也显示除zero-shot外全部为0。当前系统的主要安全缺口不是不会识别某一种故障,而是**不会在良性弱异常上不干预**。

## 6. 闭环核验的正确解释

已有 A4.4/A4.5 各12条(3场景×4 seeds):

- matched-O2:代理实际 High-step,4/4 reach,与 M 的方向一致。
- matched-O4:代理 Backstep 可脱离,但没有 forced-label `backstep_detour` 的理想化后续绕行,故不reach。
- O8:live snapshot 的归因随 oracle/realistic trigger 改变,显示冻结快照到闭环存在分布漂移。

所以 M 是“强制标签控制器后果矩阵”,不是代理闭环性能表。ERS 是在“代理原语与 forced-label controller 可对应”假设下的投影;只在 O2 等实现一致的单元可直接验证。

## 7. 论文可用与不可用表述

可用:

1. 在冻结的 Isaac 物理栈中,恢复标签干预可因果改变后果。
2. T2 中 High-step@adhesion 的代价4显著高于 Backstep@mud 的代价1,得到 `p*=0.25`。
3. B5-conflict 相对 B5-unshaped 的8场景实际动作 ERS 有配对 cluster-bootstrap 改善。
4. 代理普遍无法在 nominal 场景 abstain,这是明确失败模式。

不可用:

1. “所有9个场景对角线主导”。
2. “归因正确就必然发出正确动作”。
3. “conflict agent 的物理 regret 比所有基线低4倍”。
4. “composed ERS 等同真实闭环 safety”。
5. “real robot/real-Go2 episodes”;本实验是 Isaac Go2 physics simulation。
