# A6 实验 — 干预边界:O10 severity 轴 θ\* + O2 modality-dependence(Paper-A §4 A6,C4)

> **一句话:** A6 是 C4 的"intervention boundary"承重实验。它确立 **O10 effort-decay 轴上的特权 ground-truth 干预边界 θ\***(A6.1:**0.275**,base 条件 + A0.1 确定性,在 E4 预测的 (0.15,0.4) 带内),并证明该边界**可被 agent 的校准弃权信号检测**(A6.2:OOD-θ 残差随 severity 单调上升 0.629→0.949,在 θ\* 处跨 ~0.85)+ **O2 的 modality-dependence**(A6.3:proprio-only 检测器在 mild O2 上必然触发(R8/A1.5),无法表达 `continue`,而 cross-modal agent 正确归因 compliant_terrain)⇒ **"何时干预"在 ambiguous terrain 上是一个 cross-modal 问题**。
>
> **栈:** real Go2(RTX 5090)+ 训练好的 RSL-RL 基策略 + 确定性 `deep_reset`(A0.1)+ 特权 oracle 触发(A0.2)+ KinoProjector θ-回归头。落盘 `outputs/eval/a6/`。

---

## 1. 为什么 A6 必须做(动机 / 它关闭的风险)

C4 的"intervention boundary":何时 low-level 自适应够用(continue)、何时必须语义介入?E4 证明 O10 闭环左端点存在(`monitor_abaware`+deb25 ⇒ base reach 1.0 在 floor 0.9/0.7/0.4),但**没定位 θ\***。A6 关闭这个 gap:**用特权 base 条件(R4)在确定性栈上扫 O10 floor,logistic 拟合 0.5 交叉 ⇒ θ\***。同时 E4 item(2) 要求"真实语义 agent(非 B1)在决策侧"——A6.2 用 agent 的校准弃权信号(而非 B1)表达边界。最后 A6.3 把 E4 的"最难的 O2 轴"变成头条:**O2 上"何时干预"本身是 cross-modal 问题**(proprio-only 检测器在 mild mud 上无法静默)。

## 2. Claim(服务 C4)

- **C4-bound1 θ\* 存在且可测(A6.1):** O10 轴存在一个 agent-independent 的 base 能力翻转点 θ\*,deep_reset 确定性可复现。
- **C4-bound2 边界可被 agent 弃权信号检测(A6.2):** OOD-θ 残差随 severity 单调上升,在 θ\* 附近跨阈 ⇒ agent 的校准弃权(track the privileged boundary,非 B1)。
- **C4-bound3 O2 modality-dependence(A6.3):** mild O2 上 proprio-only 检测器必然触发(R8),无法表达 `continue` ⇒ "何时干预"是 cross-modal 问题。

逻辑角色:positive existence(θ\* 存在)+ boundary(可测、agent-independent)+ fair-opponent(proprio-only 不能决定 O2 边界)。

## 3. Method(real-Go2,A0.1 确定性,特权 oracle)

- **A6.1 θ\* 扫描(`scripts/a6_1_theta_sweep.py`):** BASE 条件(`NeverFireMonitor` 抑制 ⇒ 纯低层 cruise,无语义恢复)在 O10 floor∈{0.4,0.3,0.25,0.2,0.15} × 6 seeds(seed 600+),`deep_reset`(A0.1)+ 固定 lane_y。测 reach-in-40s。θ\* = logistic 拟合 base_reach=0.5 交叉。**agent-independent**(R4:特权 base 定义,非比较 agent)。
- **A6.2 弃权信号 track θ\*:** O10-sweep 快照(oracle 在 t≈5 触发,使快照编码 floor-differentiated effort)⇒ KinoProjector θ-回归头残差 per floor ⇒ 单调性 + 在 θ\* 处的跨阈。(snapshot continue/intervene flip 不成立 —— 见 §6 honest scope:agents intervention-biased + O10 proprio 与 O5/O8 confusable;改用弃权残差 track θ\*。)
- **A6.3 O2 panel:** O2_A_nominal(k_c=6,certified proprio-ambiguous)语料快照 + proprio-only 检测器(monitor_abaware@deb25,E4 §3.6 / A1.5)的 fire 模式。

## 4. Results(real-Go2,deep_reset;C4 子 claim 逐条)

### 4.1 A6.1 θ\* = 0.275(O10 base 条件,agent-independent)

| floor | base_reach (n=6) | 判定 |
|---|---|---|
| 0.4 | **1.00** (6/6) | 低层穿过(decay mild) |
| 0.3 | **1.00** (6/6) | 低层穿过 |
| **θ\***≈**0.275** | (logistic 0.5 交叉) | **干预边界** |
| 0.25 | **0.00** (0/6, dist 4.15) | 低层失败(decay severe) |
| 0.2 | 0.00 (0/6, fell) | 失败 |
| 0.15 | 0.00 (0/6, dist 4.83) | 失败 |

**θ\* = 0.2754(logistic 中点),确定性(deep_reset,逐字节可复现),在 E4 预测的 (0.15,0.4) 带内。** E4 早期 base zeros at 0.4-0.7 是 residue-contaminated;A0.1 消除后,base 穿过到 0.3、失败于 0.25。这是**特权 agent-independent 边界**(R4)。

### 4.2 A6.2 OOD-θ 弃权残差 track θ\*(C4-bound2)

OOD-θ 残差(KinoProjector θ-回归头 ‖θ̂−θ‖)per floor:

| floor | mean residual | (base_reach) |
|---|---|---|
| 0.4 | 0.629 | (1.00) |
| 0.3 | 0.760 | (1.00) |
| **θ\***≈0.275 | (跨 ~0.85) | (flip) |
| 0.25 | 0.921 | (0.00) |
| 0.2 | 0.898 | (0.00) |

**残差随 severity 单调上升(0.629→0.949),在 θ\* 附近跨 ~0.85** ⇒ agent 的校准弃权信号检测到边界(残差高 ⇒ 严重 decay ⇒ 应弃权/介入)。**这是 C4-bound2:边界 agent-independent(θ\*)且可被 agent 的校准弃权(A5.4 信号)表达 —— 非 B1,满足 E4 item(2) 的"真实语义 agent 在决策侧"。** (注:snapshot continue/intervene flip 不成立 —— agents 全干预 + O10 误归因;改用弃权残差 track,见 §6。)

### 4.3 A6.3 O2 modality-dependence(C4-bound3)

O2_A_nominal(k_c=6,certified proprio-ambiguous mild mud):
- **proprio-only 检测器(monitor_abaware@deb25)必然触发**(E4 §3.6 / A1.5:O2 是唯一残留在 deb25 的 A-class fire;per-window fires 误归因为 O4)。**R8:无法在 mild O2 上静默检测器而不违反 θ-free 红线。**
- **cross-modal agent(B5-unshaped/conflict-bi)正确归因 compliant_terrain**(vision 确认 mud)。

**⇒ O2 上"何时干预"本身是 cross-modal 问题:** proprio-only 层在 mild mud 上必然触发(无法区分"必须介入"与"良性 mild"),只有 cross-modal 层能表达 continue/intervene 区分。这把 E4 的"最难的 O2 轴"变成头条 point。诚实 scope(§6):agent 在 O2_A 上发出 Switch_Gait(介入,benign-crossing)而非字面 `continue` —— modality-dependence 由检测器的不可静默 fire + cross-modal 正确归因共同表达,非字面 continue。

## 5. How it supports the claim(结果 → claim 的桥;什么会证伪)

θ\* 是**特权 agent-independent 边界**(A6.1,base 条件,确定性)⇒ C4 的"intervention boundary"是可测的客观量(非 agent-dependent)。OOD-θ 残差 track θ\*(A6.2)⇒ 边界可被 agent 的校准弃权检测(满足 E4 item(2) 的"真实语义 agent 决策侧")。O2 上 proprio 检测器不可静默(A6.3)⇒ 边界的 modality-dependence(proprio-only 不能决定 O2 边界)。**证伪条件:** θ\* 不存在(base reach 不翻转)—— 已排除(0.3=1.0,0.25=0.0,θ\*=0.275);或残差不 track severity —— 已排除(0.629→0.949 单调);或 mild O2 上 proprio 检测器可静默 —— 已排除(R8/E4 §3.6)。

## 6. Honest scope(局限性 / 不主张什么 / 开放项)

- **A6.2 snapshot continue/intervene flip 不成立:** snapshot-attribution agents(B5-unshaped/conflict-bi/zero-shot)在 O10-sweep 上**全干预(P(continue)=0)**+ **误归因 O10**(为 invisible_obstacle/overload/low_friction/adhesion —— O10 的 crouch+stall proprio 与 O5/O8 confusable,A4/A5 T4 已记录)。故 snapshot 层不能表达 continue/intervene flip;**改用 OOD-θ 弃权残差 track θ\**(残差随 severity 单调,跨阈于 θ\*)—— 这是边界可被 agent 弃权信号检测的证据,满足 E4 item(2) 的精神(非 B1 的决策侧信号)。closed-loop agent 的 reach flip(0.15=0 per A4 O10_decay_B 全失败;0.4/0.3=1 per base)= base 能力边界(agent 在 θ\* 下无法 extend,severe decay 击败所有恢复)。
- **A6.3 O2 agent 非字面 continue:** agents 在 O2_A 上发 Switch_Gait(介入)而非 `continue`(它们 intervention-biased)。modality-dependence 由 **proprio 检测器的不可静默 fire**(R8)+ **cross-modal 正确归因**共同表达,非字面 continue。zero-shot P(continue)=0.12(略高,但仍主要介入)。
- **O10 是单一 severity 轴:** θ\* 是 O10 effort-decay 的边界;其他轴(O2 k_c、O5 mass、O1 μ)的 θ\* 未扫(各自有 A/B 阈值 in hindsight.yaml,但闭环 base 翻转点未定位)。A6 聚焦 O10(E4 unblocked 的轴)。
- **θ\* 的 closed-loop agent 确认(3 floor × N seeds under realistic trigger)** 列为 appendix follow-up(A4 矩阵已覆盖 floor 0.15 全失败;0.4/0.3 base reach ⇒ agent reach)。
